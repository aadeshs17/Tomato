# 🍅 Tomato – Food Delivery Web Application

Tomato is a full-stack food delivery web application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. It provides a user-friendly platform for browsing food items, managing shopping carts and placing orders, along with a dedicated admin dashboard for managing food items and customer orders.

## 🚀 Features

### 👤 User Features
- Browse food items and explore menus.
- Add and remove items from the shopping cart.
- Update food quantities.
- Manage cart and checkout workflows.
- Secure user authentication.

### 🛠️ Admin Features
- Dedicated admin dashboard.
- Add and manage food items.
- View and manage customer orders.
- Manage menu information.

### ⚡ Other Features
- Responsive user interface.
- RESTful API integration.
- JWT-based authentication.
- MongoDB database integration.
- Seamless frontend and backend communication.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/aadeshs17/Tomato.git
cd Tomato
```

### 2. Install Dependencies

Install dependencies separately in each project directory:

```bash
cd frontend
npm install

cd ../admin
npm install

cd ../backend
npm install
```

### 3. Environment Configuration

Configure the required environment variables in the backend `.env` file, including:

- MongoDB connection URL
- JWT secret key
- Other required application configurations

### 4. Run the Application

Start the frontend, admin dashboard and backend using their respective npm scripts.
